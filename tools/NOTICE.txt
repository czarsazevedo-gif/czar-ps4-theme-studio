Componentes externos
====================

O Studio Linux prepara o tema e o GP4 para empacotamento externo. O código
do editor é MIT. Essa licença não concede direitos sobre ferramentas da Sony.

orbis-pub-cmd.exe, sc.exe, di.exe, libatrac9.dll e at9tool.exe são componentes
proprietários. O repositório e os scripts de Codespaces não os distribuem
nem os obtêm. Um operador pode usar ferramentas externas para as quais
tenha acesso legítimo em um ambiente compatível.

A interface legada local pode detectar ferramentas presentes no próprio
ambiente. A interface padrão do Studio usa o bundle como saída.
